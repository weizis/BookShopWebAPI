
# BookShopWebAPI

REST API для управления каталогом книг и авторов, разработанный на ASP.NET Core.

## Функциональность

- Создание, получение, обновление и удаление книг
- Управление информацией об авторах
- Поиск и фильтрация данных
- Аутентификация пользователей
- JWT-аутентификация
- Обработка исключений
- Работа с DTO

## Технологии

- C#
- ASP.NET Core Web API
- Entity Framework Core
- JWT
- LINQ
- JSON
- REST API

## Структура проекта

| Компонент | Назначение |
|---|---|
| Controllers | Обработка HTTP-запросов |
| Services | Прикладная логика |
| Models | Модели предметной области |
| DTOs | Объекты передачи данных |
| Configuration | Конфигурация приложения |
| Exceptions | Обработка исключений |

## Запуск

Клонирование репозитория:

```bash
git clone https://github.com/weizis/BookShopWebAPI.git
cd BookShopWebAPI/API1
```

Восстановление зависимостей:

```bash
dotnet restore
```

Перед запуском необходимо настроить параметры подключения к базе данных и JWT в конфигурации приложения.

```bash
dotnet run
```

## Цель проекта

Практическое изучение backend-разработки, REST API, аутентификации и разделения ответственности между компонентами приложения.
